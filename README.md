## 🔥 About This Repository

This is my personal playground for learning and practicing **HTML** — the foundation everything else on the web is built on. Every file here reflects hands-on practice with semantic markup, page structure, and accessible design, written as I build a solid base before layering CSS, JavaScript, and frameworks on top.

No frameworks, no shortcuts — just clean, readable markup.

<br/>

## 🧡 What's Inside

| Concept | What I Practiced |
|---|---|
| 🏗️ **Semantic HTML** | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` |
| 📝 **Forms** | Input types, validation attributes, labels, fieldsets |
| 📊 **Tables** | Structured tabular data, `<thead>`/`<tbody>`, colspan/rowspan |
| 🖼️ **Media** | Images, `<figure>`, `<figcaption>`, embedded audio/video |
| ♿ **Accessibility** | ARIA basics, alt text, logical heading hierarchy |
| 🔗 **Linking & Navigation** | Internal anchors, relative paths, multi-page structure |

<br/>

## 🗂️ Repository Structure

```
html/
├── basics/           → tags, elements, document structure
├── forms/             → input types, validation, form layouts
├── tables/             → structured data practice
├── semantic-layouts/    → header/nav/main/footer compositions
├── mini-projects/         → small standalone pages
└── README.md
```

<br/>

## 🚀 Getting Started

```bash
git clone https://github.com/Ridhima-Gadalay/html.git
cd html
```

Open any `.html` file directly in your browser — no build step, no dependencies. That's the beauty of where this all starts.

<br/>

## 🌱 Why This Repo Exists

Before diving deeper into React, Next.js, and full-stack builds, I wanted a dedicated space to get comfortable with the fundamentals — writing markup that's clean, semantic, and accessible by default. This repo is that foundation, kept intentionally simple.
